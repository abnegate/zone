Or use a package manager

Homebrew and APT install the desktop app and the zone CLI, and update both with the rest of your packages.

macOS, Homebrew

$ brew tap bitecodehq/tap
$ brew install --cask zone

Debian and Ubuntu, APT

$ curl -fsSL https://apt.bitecode.ltd/pubkey.gpg | sudo gpg --dearmor -o /usr/share/keyrings/bitecode.gpg
$ echo "deb [signed-by=/usr/share/keyrings/bitecode.gpg] https://apt.bitecode.ltd stable main" | sudo tee /etc/apt/sources.list.d/bitecode.list
$ sudo apt update && sudo apt install zone

The zone CLI on its own

For servers, containers and terminals without the app. Download the binary for your platform, check it against the release’s checksums, and put it on your path.

{{ cliInstructions }}

Then sign in to your server

zone login asks for your email and password and keeps the session in your system keychain. Run zone --help for every command.

Terminal

$ zone login https://zone.example.com
$ zone run "Add input validation to the user form"
