All of Zone’s code is public in one repository. Almost all of it is MIT. The Enterprise features are source-available under the Zone Enterprise License, so you can read the code that enforces your policies.

What each license covers

  • Everything else

    Zone Community: chat, agents, models, Studio, the server, the console and the apps.

    MIT License
