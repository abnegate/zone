One platform, three parts

The parts describe what you use Zone for, not separate installs. Every feature ships in the same stack, and setup decides which local models and media runtimes to switch on.

Zone

A private AI workspace for anyone.

  • Chat with history, web search and agent tools. A tool call that writes to the host, runs a command or leaves the workspace waits for your approval.
  • A knowledge base per workspace with semantic search.
  • Sources from GitHub, GitLab, local folders and web pages.
  • Local models through Ollama, routed by LiteLLM.
  • Desktop apps for macOS and Linux, Android and iOS apps, and the zone CLI.

Zone Code

For teams that want their backlog worked.

  • Claude Code and Codex agents, signed in with your organization’s own Claude or ChatGPT subscriptions.
  • Several agent accounts, handing over mid-answer when one hits its limit.
  • Auto projects: describe a project, answer the interview, and Zone plans, builds, reviews with a second model and merges.
  • Checked work: every change gets a receipt built from the tool call, not from the model’s account of it.
  • Pull request upkeep: fixes failing checks and repairs merge conflicts.

Zone Studio

For making images, video and your own models.

  • Image, image edit, audio and video generation through ComfyUI.
  • LoRA, full fine-tune and pivotal training, on your machine or on Runpod.
  • Fine-tunes of chat models with MLX on the host.
  • Character cards as a chat’s persona.

Runs where your code and data already live

There is no hosted Zone. You run it on your own machines or your own cloud account, and it works with the model providers you already pay for.

  • Your hardware

    Docker Compose on one machine, or Helm charts for Kubernetes. Only the reverse proxy publishes public ports.

  • Your models

    Local models through Ollama, alongside Claude Code, Codex and API-key providers.

  • Your teams

    Organizations and workspaces with email invitations, built-in roles and an audit log.

  • Your privacy

    Zone itself sends no telemetry. Optional private web search can route the stack’s internet traffic through a VPN.

Get started

Install Ollama and Docker, then run setup. It asks which features to enable, shows how much disk each one needs and downloads those models.

  • Docker 20.10+ and Docker Compose v2
  • Ollama listening on port 11434: run ollama serve in its own terminal unless it already runs as a service
  • 8 GB of RAM for chat only; more for vision, image and video models
